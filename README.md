# 养分辨症 · Nutrient Triage · Triaj Nutrien

Offline-first PWA for Malaysian farmers: a visual key to plant nutrient deficiencies, with soil pH / EC interpretation, antagonisms, toxicities, look-alikes and a stage-by-stage feeding guide. 中文 / English / Malay. Crops: durian, other fruit trees, vegetables, oil palm.

**Live:** https://stanleywoosweeleong.github.io/NutrientTriage/

Single-file app (`index.html`) + `sw.js` (network-first cache — no version bumps, just edit `index.html` and push) + `manifest.json` and icons.

Built by Stanley Woo (胡瑞良) — LV LONG SDN BHD / 順豪生态榴莲园. Sources are listed inside the app (参考 → 参考来源).
